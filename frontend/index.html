📡 ClimatePredictionInput — Backend Schema

The ML model accepts 14 urban morphology features. Geographic coordinates are auto-extracted from the map click. All other fields have sensible defaults tuned for Egyptian urban environments.

Field Description
predicted_mean_temp_cLocal surface temperature in °C
target_variablePredicted variable name (mean_temperature)
